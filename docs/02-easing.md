# 2. Easing: 속도의 모양

같은 300ms라도 **언제 빠르고 언제 느린지**에 따라 느낌이 완전히 달라져요. 이걸 정하는 게 easing(timing function)이에요.

## cubic-bezier(x1, y1, x2, y2)

- 가로축 = 시간 진행(0 → 1), 세로축 = 이동 진행(0 → 1)인 그래프예요.
- 시작점 `(0,0)`과 끝점 `(1,1)`은 고정이고, 네 숫자는 곡선을 당기는 **조절점 두 개**예요.
- 곡선이 가파른 구간 = 빠르게 움직이는 구간, 완만한 구간 = 느린 구간이에요.

```css
transition-timing-function: cubic-bezier(0.2, 0.8, 0.2, 1);
```

- 첫 조절점 `(0.2, 0.8)`: 시간 20% 지점에서 이미 거리 80% 쪽으로 당겨요 → **출발이 아주 빠름**
- 둘째 조절점 `(0.2, 1)`: 남은 구간은 목표에 붙어서 천천히 접근 → **부드럽게 멈춤**

## 기본 키워드

| 키워드 | cubic-bezier | 느낌 | 쓰임 |
|---|---|---|---|
| `linear` | (0, 0, 1, 1) | 일정한 속도, 기계적 | 로딩 바, 회전 |
| `ease` | (0.25, 0.1, 0.25, 1) | 기본값 | 무난 |
| `ease-in` | (0.42, 0, 1, 1) | 천천히 출발, 빠르게 끝 | **사라질 때** |
| `ease-out` | (0, 0, 0.58, 1) | 빠르게 출발, 천천히 끝 | **나타날 때, 반응** |
| `ease-in-out` | (0.42, 0, 0.58, 1) | 양 끝이 느림 | 화면 안에서 이동 |

## 경험 법칙

- **사용자 동작에 대한 반응은 ease-out 계열.** 클릭하자마자 움직여야 "반응이 빠르다"고 느껴요.
- **들어올 땐 ease-out, 나갈 땐 ease-in.** 나가는 요소는 처음엔 머뭇거리다 빠르게 사라지는 게 자연스러워요.
- **y 값이 1을 넘으면 튕김(overshoot)**이 생겨요. 예: `cubic-bezier(0.34, 1.56, 0.64, 1)`
- 시간은 보통 **150~450ms**예요. 작은 요소는 짧게, 화면을 크게 가로지르는 이동은 길게 잡아요.
